# Asset Slots

This folder is reserved for replaceable production assets.

- `sprites/player/` for Mbavu Destroyer animations.
- `sprites/enemies/` for goons, minibosses, and Majembe.
- `sprites/backgrounds/` for Nairobi street layers.
- `audio/` for music, hits, jumps, and UI sounds.

The prototype currently creates placeholder textures in `BootScene` so the game runs without external files.
